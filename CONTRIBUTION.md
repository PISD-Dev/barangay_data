# Contributions

Contributions to the main dataset are welcome. Any proposed corrections, additions, or other changes should be supported by a reliable source and documented separately from the main dataset.

Ideally, contributions should be submitted as a separate CSV file that clearly identifies the record and field being changed, provides the proposed new information, and includes the source supporting the change. This allows changes to be reviewed and incorporated while maintaining a transparent record of modifications to the original data.

A suggested format is:

| `RECORD_ID` | `FIELD` | `CURRENT_VALUE` | `PROPOSED_VALUE` | `SOURCE` | `NOTES` |
|---|---|---|---|---|---|
| `12345` | `BRGY_TELNO` | `02-1234-5678` | `02-1234-5679` | `https://example.gov.ph/...` | Corrected apparent transcription error |

Please do not modify the main dataset directly when submitting a contribution. Keeping proposed changes separate makes it possible to verify each change, preserve the original data, and maintain an auditable history of corrections.

## Note the following formats:
- Mobile Numbers: 63XXXXXXXXXX
- Landline Numbers: 02XXXXXXXX
- Names: All-caps
